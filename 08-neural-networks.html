Neural Networks & Backpropagation

A neural network is logistic regression stacked, with a squiggle in between. That squiggle — the nonlinearity — is what lets it represent things a line never could, and backpropagation is the bookkeeping that makes training such a stack possible at all.

  • Explain why a network without nonlinearity is just a linear model
  • Trace a forward pass and a backward pass through a small network
  • Choose an activation function and know why ReLU won
  • Train an MLP in the page and watch it bend a decision boundary
  • Recognise vanishing and exploding gradients from the symptoms

Why stack at all?

Logistic regression draws one straight boundary. Plenty of real problems aren't separable by a line — the classic being XOR, where the positives sit in opposite corners. No line splits them. Stack two linear layers without a nonlinearity and you still can't: W₂(W₁x) = (W₂W₁)x is one matrix, one line.

🔑
The whole trick, in one line

Insert a nonlinear function between the layers — a = f(W₁x), then ŷ = W₂a — and the composition is no longer linear. Each hidden unit carves one half-plane; the next layer combines them into arbitrary shapes. Depth stacks that ability exponentially.

Anatomy of a network

Three layers of vocabulary and you can read any architecture diagram:

🔢

Neuron

a = f(w·x + b). A dot product, a bias, a squash. That's the atom.

📚

Layer

Many neurons sharing an input — one matrix multiply: A = f(XW + b).

🏗️

Depth

Layers stacked. Early layers learn simple features, later ones compose them.

🎯

Head

The final layer shaped to the task: 1 output + sigmoid, K outputs + softmax, or a raw number.

One forward pass, one backward passStep-through
  1. One example enters as a vector, e.g. x = [0.7, −0.3]. In a real batch there are thousands of these stacked into a matrix and processed together — that's what makes GPUs worth using.
  2. Each hidden unit computes z = w·x + b — three dot products, one matrix multiply. Every line in the diagram is one learnable weight.
  3. Apply ReLU(z) = max(0, z) elementwise. Negative pre-activations become exactly zero — those units are “off” for this example, which is what makes the network piecewise-linear rather than linear.
  4. The hidden activations are combined into one number, then squashed by a sigmoid into a probability. For multi-class you'd have K outputs and a softmax instead.
  5. Compare with the label: L = −[y·log(ŷ) + (1−y)·log(1−ŷ)]. This single number is the only feedback the whole network receives.
  6. Differentiate the loss w.r.t. the output. With sigmoid + cross-entropy this collapses to the beautifully simple ∂L/∂z = ŷ − y.
  7. Each weight's gradient is (ŷ − y) × hᵢ — “how wrong we were, times how much this unit contributed”. The error also flows back to each hidden activation.
  8. ReLU's derivative is 1 where it was active and 0 where it wasn't, so gradient flows only through units that fired. Units that were off learn nothing from this example.
  9. Multiply once more to get gradients for the first weight matrix. Every gradient in the network is now known after exactly one backward sweep — cost roughly 2× the forward pass, regardless of depth.
  10. The optimizer applies w ← w − η·g to every parameter, gradients are zeroed, and the next batch starts. Millions of repetitions of this loop is all training is.
🏭
Analogy: blame assignment on a production line

A defective product comes off the line. Backprop walks the line backwards, asking each station: “given how much you changed the product, how much of this defect is yours?” Each station adjusts slightly, in proportion to its contribution. Doing this for billions of stations is only feasible because each one's local answer is a simple derivative.

Activation functions

The nonlinearity determines how gradients flow. This is not a cosmetic choice — it's the difference between a network that trains and one that doesn't.

Width, depth and what a network can represent

The universal approximation theorem says one hidden layer, given enough units, can approximate any continuous function. It is also nearly useless as engineering advice: “enough” can mean exponentially many units. Depth is how you get the same expressiveness at a manageable size, because layers compose features instead of enumerating them.

Wider

More features per level. Easy to parallelise, memory-hungry, quick gains at first, then diminishing. Modern scaling tends to grow width and depth together.

Deeper

More composition — edges → textures → objects. Exponentially more expressive per parameter, but harder to train: gradients have to survive more multiplications (the subject of Chapter 9).

Vanishing and exploding gradients

Backprop multiplies a chain of local derivatives. Multiply 30 numbers that average 0.6 and you get 2×10⁻⁷ — the early layers effectively stop learning. Multiply 30 numbers averaging 1.4 and you get 24,000 — the update blows the weights apart.

🛣️
Residual connections, in one sentence

Compute x + f(x) instead of f(x), so there's a path where the gradient passes through unchanged (derivative 1) no matter how deep the stack. That's why networks jumped from ~20 layers to 1,000+ almost overnight, and why every transformer block has two of them (Chapter 14).

⚠️
Common mistakes
  • Forgetting the nonlinearity (or putting an activation after the final layer when the loss already applies one). Both silently cripple the model.
  • Applying softmax then cross-entropy in frameworks whose loss expects logits — the double softmax flattens gradients.
  • Initializing all weights to zero. Every unit computes the same thing and receives the same gradient forever; the network has one effective neuron.
  • Not scaling inputs. A feature with range 0–100,000 saturates activations immediately and the first layer never recovers.
  • Reaching for a deeper network before checking the data. Depth rarely fixes label noise, leakage or a missing feature.

Interview drill

Warm-up: Why can't a 10-layer network without activation functions learn XOR?

How a strong answer sounds
Composing linear maps gives another linear map: the product of the weight matrices is a single matrix, so the model can only draw one hyperplane regardless of depth. XOR isn't linearly separable, so no such boundary exists. The nonlinearity is what makes composition add expressiveness rather than collapse.

Deeper: Your 40-layer network trains far worse than the 8-layer version on the same data. What's happening and what do you do?

How a strong answer sounds
Most likely an optimization problem rather than a capacity one — the deeper model can represent everything the shallow one can, so it should not be worse. I'd check gradient norms per layer: if early-layer gradients are orders of magnitude smaller, it's vanishing signal. Fixes in order of impact: residual connections, normalization (LayerNorm/BatchNorm), a sane initialization scheme scaled by fan-in, warmup on the learning rate, and gradient clipping if the tail of the distribution is spiking. If gradients look healthy and it's still worse, I'd suspect too-high a learning rate for the depth, or insufficient data for the parameter count.

🧠 Key takeaways

  • Without a nonlinearity, any stack of linear layers collapses to one linear layer.
  • Backprop is the chain rule applied backwards through the graph — one sweep gives every gradient, at roughly 2× the forward cost.
  • ReLU-family activations keep gradients alive; saturating ones (sigmoid, tanh) throttle them.
  • Depth buys composition; residual connections are what make depth trainable.
  • Vanishing/exploding gradients have recognisable symptoms and standard fixes — diagnose before redesigning.

Check your understanding

You remove all activation functions from a 5-layer network. What is the result equivalent to?

The product of the weight matrices is one matrix. It trains fine — it just can't represent anything nonlinear.

What is ReLU's derivative for a negative input?

That's both ReLU's strength (sparse activations, cheap) and its weakness: a unit stuck negative for every example receives no gradient and never recovers — the “dying ReLU”.

You initialize every weight to 0. What goes wrong?

Symmetric initialization means identical forward values and identical gradients, so the units never differentiate. Random initialization breaks that symmetry.

A 50-layer network's early-layer gradients are ~1e-9 while the last layer's are ~1e-2. What helps most?

Classic vanishing gradients. A skip path with derivative 1 lets gradient reach early layers unattenuated; normalization keeps activation scales stable along the way.

Roughly how expensive is a backward pass compared with a forward pass?

Each layer's backward step computes gradients w.r.t. both its inputs and its weights — two matrix multiplies instead of one. The usual rule of thumb: a training step costs about 3× a forward pass, which is where the “6ND FLOPs” training estimate in Chapter 16 comes from.
